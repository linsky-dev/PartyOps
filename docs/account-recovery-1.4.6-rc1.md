# PartyOps 1.4.6-rc.1 账号恢复

## 登录页面与账号设置

普通用户向管理员核验身份后领取一次性恢复凭据。在主机登录页打开账号恢复，粘贴凭据并选择找回用户名或修改登录信息。找回用户名同样消耗凭据。管理员重新签发后，上一份凭据立即失效。普通恢复凭据有效期为 30 分钟，可在用户管理中撤销。

已登录用户可用当前密码验证后修改用户名、密码或两者。修改成功后，请在主机和协同终端使用新登录信息重新登录。用户 ID、权限和业务关联随账号保留。

管理员可用当前密码在账号设置中生成一次性离线恢复码。生成后请离线保管，再生成时旧码失效。账号禁用、归档、角色变化或登录信息修改会撤销未用恢复凭据。

## 主机本机恢复

降级前请确认所用修复版本能够读取当前数据库与认证状态。账号恢复迁移采用前向修复路径。已撤销的会话和凭据不应随旧数据库回存重新生效。

在仍知道应用管理员密码时，完成 1.4.6 数据库升级，使用正常服务管理流程停止主机，确认原数据目录。在提升权限的主机交互终端中，用安装包内的主机可执行文件运行 `--account-recovery authorize --data-dir`，并给出已配置数据目录的绝对路径。Windows 主机可执行文件名为 `PartyOps.exe`。交互输入应用管理员用户名与密码，离线保存只显示一次的本机维护授权码。工具不接受在命令行参数中传入密码或恢复码，也拒绝重定向标准输入或标准输出。

如果之后忘记管理员账号，停止主机后在同样的终端运行 `--account-recovery issue --data-dir`，输入原主机数据目录和已登记的本机维护授权码。此操作只签发一枚有效 30 分钟的管理员恢复凭据，并消耗本机维护授权。重新启动主机后，从登录页用该凭据找回用户名或修改登录信息。恢复后用新登录信息重新登记本机维护授权。

Windows 要求提升后的管理员令牌、固定本机磁盘，以及安装器已保护的服务数据目录所有者与 DACL。Linux 和 macOS 要求 root 交互终端、实际本机路径及禁止其他账号写入的数据目录。工具和服务共用数据目录实例锁，并将签发与审计一起提交。尚未预先登记本机维护授权时，请使用已保管的离线恢复码或另一名仍可登录的管理员协助。工具的真实安装包验证以发行验收矩阵为准。

## 设备入网加密和密钥运维

新设备的短期入网重试密文使用 SM4-GCM。原有 Fernet 记录保留读取路径。Windows 的新密钥由同一个主机服务账号的 DPAPI 保护。Linux 和 macOS 的新密钥在服务账号独占的目录与文件中保存。主机迁移需要独立保全受保护的 `secrets/enrollment-keys`、旧 `secrets/local-recovery-fernet.key`、CA 材料和 `secrets/pki-root-sha256`，普通业务备份不能替代密钥备份。Windows 服务账号身份或机器变化时，先核对原 DPAPI 解封能力。缺钥、密文认证失败或运行时缺少算法时，相关操作会停止并返回可归类的诊断。国密能力范围为恢复摘要及指定设备入网密文，具体平台以最终包内运行时检查为准。

从备份恢复 Linux 或 macOS 主机时，Fernet 密钥和 CA 私钥需要归主机服务账号所有，权限设为 `0600`。程序会拒绝打开权限过宽或通过链接替换的私钥。Windows 主机的密钥文件沿用安装器收敛后的服务数据 ACL。
