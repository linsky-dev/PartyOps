# Windows 安装与覆盖升级说明

本次安装包：`PartyOps_1.4.5-rc.6_windows_amd64_startup-20261018.exe`。

这是 Windows x64 完整安装包。下载后，可用同名 `.sha256` 文件核对安装包；本说明不重复列出校验摘要。

## 已有版本覆盖升级

1. 先使用应用内备份功能导出备份，妥善保存，并记录当前业务数据目录。
2. 退出正在运行的 PartyOps，运行本次安装包，选择原安装目录完成覆盖安装；出现 Windows 授权提示时按正常流程确认。
3. 安装后启动 PartyOps，沿用原运行模式和原业务数据目录，检查原账号、事项、附件及日历是否可用。

不需要先卸载旧版，也不要删除数据库或原业务目录。请保留安装前备份，直到确认原数据和所需功能正常。

首次安装可直接运行完整安装包，再按向导选择运行模式和业务数据目录。切换运行模式时请按向导操作，并正常确认 Windows 授权提示。
