# 2026-09-27 发布范围与版本说明

状态：发布准备中，尚未上传或上线。最后核对：2026-09-27。

## 用户确认的范围

本次复用此前通过用户产品使用验收的安装包，并新增龙芯普通功能安装包。Windows ARM 适配延期；Windows x86 若剩余适配能够及时完成则纳入，尚未据此认定当前候选包通过。复杂、需要重新编译的 AI 适配不阻塞普通功能发布。

计划更新六个已有 RC6 平台安装包：Windows x64、Windows 7 x64、Linux DEB x64/ARM64、Linux RPM x64/ARM64；新增龙芯 Loong64 RC6。各包绑定自身构建来源、文件摘要及原始验收记录，不宣称由同一源码快照构建。macOS 双架构暂保留官网已有 RC4 下载及原清单，不将其改名为 RC6。

## 验收与限制

六个已有包采用各自精确 SHA 对应的 `user-approved-product-use-acceptance` 记录，并保留原记录中的限制；这不等同于全部十三项生命周期或全部环境通过。

龙芯已完成原版 Deepin 25.2.0 模拟环境中的安装、实际业务、中文 OCR、WPS 排版与逐页金样、Firefox 界面、重启后数据保留、卸载保留和重装恢复、测试数据清理。详见 `qa/vm-lab/release-preparation/loong64/first-release-audit-20260927.json`。本地 AI 暂不提供，跨机器协同和其他发行版没有据此获得验证；排版仍需外部 WPS 与所需字体。

公开历史核对未发现旧龙芯包，仅“从旧公开同架构安装包升级”记为不适用。同包重装恢复不冒充跨版本升级，原完整矩阵的 blocked 回执保留。

## 发布实现

默认完整发布门禁保持原有严格规则。本次使用显式范围清单，逐包核对准确文件、验收范围和构建来源，记录未覆盖项；不生成完整矩阵通过结论。

官网按各下载卡自身版本及对应清单校验，不用同一版本标签覆盖不同版本的包。新下载入口仅在国内公开地址完整回读、GitHub 同批资产核对和官网预览验收完成后开放。现有签名在线更新目录及累计下载计数保持原有含义；本次不以完整安装包冒充签名更新包。

## 上线与回滚

按既有 `docs/domestic-release-workflow.md` 执行国内上传、完整回读、GitHub Release、EdgeOne 预览与生产部署；不触发远端 CI。发布源代码提交与每包原始构建来源分别记录。

上线前保留旧官网部署与公开清单。生产回归失败时恢复上一条已核验官网部署，不覆盖不可变公开包，不删除发布审计证据或下载累计数据。旧本地制品仅在确认不再被当前发布、验收或回滚引用后按精确路径清理。
